# 会话选模型下拉改为两列右幕式布局

**Status:** done

**Blocked by:** 无——可立即开始

**构建内容：** 消息输入框的模型选择下拉中，模型列表从单列分组（厂商 section 内平铺模型）改为两列右幕式——左列厂商，右列当前选中厂商的模型。左列点击某厂商后右列联动刷新为该厂商的模型。方向键在厂商/模型间移动、回车选中等键盘操作在改动后仍可用。根菜单（模型/推理等级 + 后续配置入口行）不变。

**验收标准：**

- [ ] 模型 pane 呈现两列：左列行数与厂商数一致；右列显示当前选中厂商的模型
- [ ] 切换左列选中厂商，右列随之只显示该厂商模型
- [ ] 无障碍：方向键可经左列厂商集移动，可进入右列模型并回车选中；两列各自可滚动
- [ ] 现有选择、load 失败重试、空态、reasoning 渲染行为无回归
- [ ] `pnpm run test:gui` 绿；新增两列交互的组件 spec 通过
