# 聊天长列表窗口化（虚拟化或头部淘汰）

**Status:** ready-for-agent
**Blocked by:** 无——可立即开始

**构建内容：** 聊天长列表窗口化：对已渲染行做虚拟化，或对窗口头部做淘汰回收（配合已有 historyIncomplete 标记，淘汰后"加载更早消息"按需重拉）。分页机制从"只控制拉取不控制保留"变为拉取与保留都有界。对用户可感知：长会话重度回翻后继续收发消息不因历史页堆积而变慢，DOM 与内存不再随回翻线性增长。

**验收标准：**

- [ ] 回翻 1000+ 条后，新消息 append 的 reconcile 成本与回翻量无关（基准）
- [ ] 滚动位置在淘汰/重拉后保持稳定不跳变（交互测试）
- [ ] historyIncomplete 边界与"加载更早"入口行为不变（现有测试全绿）
- [ ] 内存随回翻有界（长会话压力下 DOM 节点数有上限）
